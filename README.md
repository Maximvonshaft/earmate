# Earmate

初始版本的视觉规则驱动采集框架核心库，提供以下能力：

- 规则 Schema 数据结构（基于 `dataclasses`），覆盖入口信息、字段选择器、分页、详情、调度等配置。
- 简易执行器 `RuleExecutor`，结合内置的轻量 DOM 解析器执行规则并输出结构化结果。
- 单元测试示例，验证基础字段抽取与 URL 分页逻辑。

## 开发环境

- Python 3.11+
- 依赖：标准库，无第三方运行时依赖。
- 开发工具（可选）：`pytest`、`ruff`

运行测试：

```bash
pytest
```

运行代码规范检查：

```bash
ruff check
```
